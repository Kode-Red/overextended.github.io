# Shared

## lib.switch

A fast, flexible switch-case utility for Lua. Supports single values, multi-value lists, predicate functions, and a `"default"` case. Optional JS-style **fallthrough** and explicit `breakFn()` control.

### Signature

- valueOrArgs: `any | { value:any, ... }`  
- fallthrough?: `boolean` (default: `false`, stop after first match)  
- cases: `SwitchCases`  
- ...: `any`

```lua
lib.switch(valueOrArgs, fallthrough, cases, ...)
```

**Returns:**

- result: `any` — return value from the executed case (last result when falling through)

### Types

```lua
--- @alias SwitchMatch any | "default" | any[] | fun(val:any):boolean

--- @class SwitchCase
--- @field match  SwitchMatch
--- @field action fun(breakFn:fun():nil, ...:any):any

--- @alias SwitchCases SwitchCase[]
```

---

### Behavior

- If `fallthrough == false` (default): run **only the first** matching case.  
- If `fallthrough == true`: run the first match **and continue** through subsequent cases until:
  - cases end, or
  - the case calls `breakFn()`.

- `"default"` runs only if **no** earlier case matched.
- You can pass args either as variadics…  
  `lib.switch(value, false, cases, arg1, arg2)`  
  …or as a table:  
  `lib.switch({ value, arg1, arg2 }, false, cases)`

---

## Examples

### 1) Basic value match (no fallthrough)
```lua
local cases = {
  { match = 1, action = function() return "one" end },
  { match = 2, action = function() return "two" end },
  { match = "default", action = function() return "default" end },
}

local result = lib.switch(2, false, cases)
print(result) -- "two"
```

### 2) Default when no match
```lua
local cases = {
  { match = "open", action = function() return "opening" end },
  { match = "close", action = function() return "closing" end },
  { match = "default", action = function() return "noop" end },
}

print(lib.switch("pause", false, cases)) -- "noop"
```

### 3) Multi-value list
```lua
local cases = {
  { match = {2,4,6,8}, action = function(_, n) return n .. " even" end },
  { match = {1,3,5,7,9}, action = function(_, n) return n .. " odd" end },
  { match = "default", action = function(_, n) return tostring(n) .. " ?" end },
}

print(lib.switch(6, false, cases, 6)) -- "6 even"
```

### 4) Predicate functions
```lua
local cases = {
  { match = function(v) return v < 0 end, action = function() return "neg" end },
  { match = function(v) return v > 0 end, action = function() return "pos" end },
  { match = "default", action = function() return "zero" end },
}

print(lib.switch(-3, false, cases)) -- "neg"
print(lib.switch( 0, false, cases)) -- "zero"
print(lib.switch( 9, false, cases)) -- "pos"
```

### 5) Fallthrough enabled (JS-style)
```lua
local cases = {
  { match = "start", action = function() print("init") end },
  { match = "start", action = function() print("load") end },
  { match = "default", action = function() print("done") end },
}

lib.switch("start", true, cases)
-- init
-- load
-- done
```

### 6) Early break to prevent fallthrough
```lua
local cases = {
  { match = 1, action = function(breakFn) print("once"); breakFn() end },
  { match = 1, action = function() print("won't run") end },
  { match = "default", action = function() print("default") end },
}

lib.switch(1, true, cases)
-- once
```

### 7) Passing arguments (variadic)
```lua
local cases = {
  { match = "add", action = function(_, a, b) return a + b end },
  { match = "mul", action = function(_, a, b) return a * b end },
  { match = "default", action = function() return -1 end },
}

print(lib.switch("add", false, cases, 10, 5)) -- 15
```

### 8) Passing arguments (table form)
```lua
local cases = {
  { match = "concat", action = function(_, a, b) return a .. b end },
  { match = "default", action = function() return "n/a" end },
}

print(lib.switch({ "concat", "Hello ", "World" }, false, cases)) -- "Hello World"
```

### 9) Fallthrough return value = last case result
```lua
local cases = {
  { match = 3, action = function() return "first" end },
  { match = 3, action = function() return "second" end },
  { match = "default", action = function() return "tail" end },
}

print(lib.switch(3, true, cases)) -- "tail"
```

### 10) Mixed: list + predicate + default
```lua
local cases = {
  { match = {100,200}, action = function(_, v) print(v, "is preset") end },
  { match = function(v) return v > 150 end, action = function(_, v) print(v, "is big") end },
  { match = "default", action = function(_, v) print("fallback", v) end },
}

lib.switch(200, true, cases, 200)
-- 200 is preset
-- 200 is big
-- fallback 200
```

### 11) Guard-heavy default only
```lua
local cases = {
  { match = "default", action = function(_, name) return "Hi " .. (name or "Guest") end },
}

print(lib.switch("nope", false, cases, "Dakota")) -- "Hi Dakota"
```

### 12) Control flow with side effects
```lua
local door = { locked = false }

local cases = {
  { match = "lock",   action = function() door.locked = true  end },
  { match = "unlock", action = function() door.locked = false end },
  { match = "default",action = function() end },
}

lib.switch("lock", false, cases)
-- door.locked == true
```

---

### Tips

- Prefer `lib.switch(value, false, cases, ...)` in hot paths (faster than table-args).  
- Put `"default"` **last** for clarity.  
- Use lists (`{...}`) or exact values for fastest O(1) matches; predicates run only if no value/list hit.  
- Call `breakFn()` inside a case to stop fallthrough early.
